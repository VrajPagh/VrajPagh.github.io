# Vraj Paghdal Engineering Portfolio

A responsive engineering portfolio built for GitHub Pages using plain HTML, CSS, and JavaScript.

## Publish on GitHub Pages

1. Open your `VrajPagh.github.io` repository.
2. Delete the old placeholder README if desired.
3. Upload every file and folder from this repository.
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/ (root)`, then save.
8. Your site will appear at `https://vrajpagh.github.io`.

## Customize before publishing

Search the files for these placeholders:

- `YOUR_EMAIL@example.com`
- LinkedIn URL
- Resume placeholder
- Placeholder SVG project images
- “Add date”
- Any text beginning with “Replace” or “Add”

## Add your resume

Replace `resume.pdf` with your real resume while keeping the same filename.

## Add project images

Put your images in `assets/images/`, then change the image paths in `index.html`.

Example:

```html
<img src="assets/images/my-robot.jpg" alt="VEX robot at competition">
```

## Edit project pages

Project pages are located in the `projects/` folder. Each contains sections for:

- Problem
- Your role
- Design process
- Testing
- Results
- Lessons learned

## Recommended image sizes

- Homepage project cards: 1600 × 1000 pixels
- Project hero images: 1800 × 1100 pixels
- Use JPG or WebP for photos
- Use PNG or SVG for diagrams and CAD screenshots

## Local preview

Double-click `index.html`, or use Visual Studio Code with the Live Server extension.
